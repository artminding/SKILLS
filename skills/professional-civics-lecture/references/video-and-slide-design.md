# 背景视频与丰富画面的制作规范

生成大纲、讲稿时间表、逐页PPT提示词或HTML时应用。本规范不要求回溯改写用户未要求修改的既有课件。

## 一 每话题的视频安排

每个12—15分钟话题内安排3分钟短视频，固定3分钟。视频主要交代历史背景、人物关系、事件经过和基础概念；非历史专题相应交代现实背景与基础知识。教师用剩余时间完成重点澄清、专业分析和价值判断，不重复逐字复述视频，也不把专业分析全部交给视频。

15分钟话题可分为：导入1分钟＋视频3分钟＋情境澄清与故事补充4分钟＋专业分析4分钟＋平台互动或迁移2分钟＋小结和切换1分钟。六话题合计90分钟；综合写作任务需更长时，在本话题内重新分配，视频仍保留3分钟。视频播放前提出一个观察焦点，播放后用一个过渡句回到知识点。

讲稿用【教师提示 V01｜视频3分钟，地址待替换】标识播放动作，不计入口播字数。两万字全稿应附实际主讲路线及备用段，依据扣除视频等活动后的时间测算，不能承诺全文均可念完。

## 二 独立代码与可替换配置

为每个话题分配唯一代码 VIDEO_TOPIC_01、VIDEO_TOPIC_02……。代码是查找标识，不是假播放地址。单独交付视频清单与配置；不把长链接分散硬编码在每张幻灯片中。

视频清单字段：代码、对应话题、讲稿段落/PPT页、背景知识目标、必须交代的事实、建议画面、预留时长、播放前观察焦点、播放后衔接、来源和授权状态。素材未定时，后两项明确“待教师选定后核验”。

HTML可采用集中配置（每话题一项）：

```javascript
const VIDEO_CONFIG = {
  VIDEO_TOPIC_01: {
    title: "话题一：背景与基本经过",
    type: "file", // file：本地或直链视频；page：普通网页链接
    url: "", // 教师替换此处，例如相对路径 media/topic01.mp4
    plannedSeconds: 180,
    startSeconds: 0,
    endSeconds: null // 教师选定后填写；不能伪造片段时间码
  }
};
```

未填url时，呈现完整的背景导览页：视频标题、2—3个观察焦点、3分钟预留时长，以及“视频待配置”状态；不显示破损播放器、不请求代码字符串地址。配置代码和修改说明放在独立附件/源代码中，不占学生正文。file类型使用原生video控件；page类型明确“打开视频网页”，不要将普通网页URL冒充视频直链。播放由点击触发，切页暂停，网络或文件失败给出可理解提示。设置截取区间时须实际实现结束暂停；跨域、平台登录或禁止嵌入时使用正常外链。

教师替换后核对：链接可达、视频内容与知识目标相符、片段实际时长3分钟、字幕与史实准确、来源和使用授权可说明。未观看的视频只标“待审片”，不得声称已通过内容审查。按用户要求可提供候选检索词，但不擅自选定或下载视频。

## 三 题库与学生课件分离

默认不生成单选题、多选题、判断题、标准答案或解析PPT页，也不在HTML中制作答题按钮。每话题默认1题，独立交付Word教师题库，逐题附答案、解析和插入位置（话题号、P页码、页标题及投题时机）；CSV/平台表按需补充。具体格式及变更同步见 [交付结构](deliverable-structure.md)。教师题库包含答案不代表学生课件可以提前显示答案，位置标注也不代表已在幻灯片中插入题目。题目和讨论的时间仍计入90分钟。

可以保留导入问题、材料比较的观察焦点、作品细读及专业实践任务。这些是教学内容，不能因取消练习题页而一并删除。原题页如果需要改版，应转为证据对读、概念关系或情境分析页，不仅删去答案后保留选项。

## 四 丰富内容与结构，而非堆字

每话题至少3张实质内容页；视频导览、纯转场和目录不计数。常用递进为“背景与情境—证据与因果—专业解释与当代应用”，可增加人物行动链、文本细读或比较页。

每页围绕一个中心问题组织互相关联的信息：例如主图＋时间地点＋人物任务＋因果标注，或短文本＋关键词高亮＋细读批注＋结论。材料与分析都要具体，不能只有三句概括，也不能把讲稿整段塞进页面。信息丰富度来自证据、层次和关系，不来自图标数量、无关装饰或密集卡片。

同一话题按内容选用至少两种适宜结构：

- 历史情境：经核实地图/遗址照片与事件信息带；图片不足时用非地理任务关系图。
- 过程与选择：时间线或行动链，交代条件、选择、后果；箭头明确表示时间或因果，不能混用。
- 证据对读：两则短材料并列，标来源、异同、可支持的判断和证据边界。
- 人物与物件：人物任务、物件细节、生活处境与意义之间的关系。
- 专业细读：必要短引、关键词高亮、侧栏批注、概念解释及适用边界。
- 框架与应用：概念关系图搭配一个具体应用例子；避免只有方法名称。

模板决定配色、字体层级、图片处理和构图语言；内容决定具体结构。历史照片、现状照片、文物、艺术创作和示意图要分别标识。不得为画面丰富虚构地图、对白、数据或历史现场。

## 五 逐页提示词字段

每页填写以下字段，连同统一风格说明即可独立交给AI制作：

1. 页码、话题、讲稿定位、页标题与该页要解释的核心问题。
2. 实际上屏文案：标题、背景信息、材料/短引、分析标注、结论及讲稿定位条；指出加粗词语与必要来源注。定位条按下述规则逐页给出原文，不能只写“添加导航”。其他元素只填写该页实际需要的内容。
3. 主视觉与内容：明确拍摄对象或图示节点，选择理由、来源编号和授权；无图时采用何种有信息量的替代结构。
4. 布局：画幅比例、主次分区、面积比例、对齐方式、阅读顺序及字号层级。例如“左侧55%为两则短材料，右侧45%用三条对应批注解释差异”。
5. 关系：连线/箭头/颜色编码的具体含义，以及学生应看出的因果、时序、比较或层次。
6. 展示顺序：先材料后分析或静态展示；不默认设计题目与答案揭示。
7. 视频关联：如为视频页，给出唯一代码、预算、观察焦点；否则标无。
8. 边界：教师提示、制作指令不入画面；短引署名、图像类别、必要事实限定不能省略。

验收时先判断“学生从画面能看到什么具体材料、理解什么关系”，再检查字号、留白、图片清晰度和溢出。不能只凭页数、文字量或使用了多种模板判定合格。

### 讲稿定位条：必须实际画入页面（v2.8.2）

- 每张对应讲稿的页面（包括内容、话题转场、视频导览和拆分页）都提供独立的“实际上屏定位文字”字段，格式为“话题编号｜话题名称 · 对应小标题｜P页码”。话题编号、名称及小标题沿用最终讲稿原文与编号，不自行改写成宣传式标题；主标题可另作视觉提炼，但不能替代定位条。需要定位到三级单元时补入该级标题；不存在的小标题不编造。封面、总目录和来源页等不对应具体段落的页面只标其真实功能与页码。
- 示例：若讲稿原文为“话题1｜湘江战役”及“（一）渡口、阻击与后卫的相互依赖”，P03的字段应直接写成“实际上屏定位文字：话题1｜湘江战役 · （一）渡口、阻击与后卫的相互依赖｜P03”。示例不能替代当前课程的实际标题。
- 定位文字必须小于正文、明显弱于主标题，默认16:9标准幻灯片采用12—14 pt（1920×1080图片约24—28 px，其他尺寸等比例换算）。全套统一选择画面顶部或底部的一侧对齐位置，不居中占据主视觉区；距边缘至少画幅高度的2%，预留专用留白，与来源注、字幕分开。采用清晰、低视觉权重但对比充足的文字，复杂图片背景加简洁底衬，不用低透明度造成难辨。
- 标题过长时允许在同一顶部或底部区域折为两行，不删掉定位词、不以省略号或继续缩字解决。拆页后保留相同话题与小标题，更换页码；跨多个小标题的综合页列出实际涉及的小标题，不强造一对一关系。
- 统一风格说明和每页提示词都须明确：“定位条是必须显示的导航文字，不是教师提示或制作指令；必须绘入最终幻灯片/生成图片，不得省略、改写或仅放在备注中。”交给其他PPT或图像技能时一并传递，不能依赖对方读取讲稿或幕后索引。
- 验收逐页对照最终讲稿：话题与小标题是否一致、页码是否正确、顶部/底部小字是否完整清晰且未裁切、是否干扰正文。图片式成品须实际查看图片中的文字；未制作成品时只能说明提示词已检查，不宣称画面已通过验收。


## 六 逐页信息提炼与逻辑关系（v2.2）

用户要求内容丰富时，逐页审视材料是否足以支持理解，不只增加页数、字体或装饰。默认每张实质内容页交代三个相连的问题：有什么具体材料或事实；它说明什么、依据是什么；本页形成什么核心判断或专业启示。三项可以合并呈现，不强制套用三栏版式。封面、来源页、视频导览页按其功能增加必要信息，不硬塞理论分析。

- **信息含量**：将材料提炼为人物、时间、处境、行动、证据、概念、后果等有效信息。补充能解释关系的内容，删除同义重复和泛泛赞语。新增史实必须核查来源；教学归纳标明性质。
- **重点识别**：关键词和核心判断句用加粗、字号或少量强调色标识。每页建立清晰的主次层级，不整段加粗，也不让所有信息同等醒目。
- **逻辑连接**：关键词与重点句不能只是并列摆放。按内容选择因果、时序、对照、条件、层次或相互支撑关系，必要时用连线、箭头、对照表或关系带表达。标明关系含义；时间先后不能冒充因果，非线性关系不能强拉为单向链条。
- **结论依据**：核心判断应能回指本页的事实或材料；专业启示应说明从历史材料到专业方法的连接，不能突然跳到励志结论。
- **整体多样性**：保留模板风格，按内容使用时间线、图文分析、文本批注、对读或概念图。不得把所有页面机械改成相同三栏加箭头。
- **投影可读性**：内容过多时先精简语言与重复信息，再调整结构；仍拥挤则拆页。不能通过持续缩小正文字号满足信息量。新增画面内容不自动增加课堂时长，仍保留每话题3分钟视频和90分钟总预算。

逐页提示词增加三个字段：

1. **信息提炼**：列出本页实际使用的事实/材料、必要限定、解释及核心判断。
2. **关键词与关系**：给出需强调的词句、节点之间的具体关系和方向，以及依据。例如“馆藏身份 → 使用处境 → 用途改变 → 历史理解”，标为物证阅读路径，不标为事件因果。
3. **阅读收获**：用一句话写明学生看完本页应能解释什么；检查该收获是否由画面材料支持。

示例：文学细读页可用“词语选择 → 形象关系 → 情感组织 → 精神表达”作为分析路径，配具体短引与对应批注；不能只画四个抽象词框。物件页应将身份来源、用途变化与历史处境对应起来，不能依据实物擅自编造人物对白。


## 七 HTML实现约束（v2.4）

生成HTML时必须配合 [HTML技术规范](html-technical-spec.md) 实施。内容丰富度不能以裁切、无限缩字或窄屏不可读为代价；视频、关系图与正文均须响应式适配。
