# HTML课件技术规范（v2.4）

制作或修改HTML课件时必读。技术约束服务于学生观看、教师操作和后续维护；不是在画面中展示的教学内容。

## 一 响应式布局与两种观看模式

- 必须设置 `meta name="viewport" content="width=device-width, initial-scale=1"`；不禁止用户缩放。
- 横屏演示默认16:9，使用 `aspect-ratio:16/9` 和可用宽高共同约束舞台。保留完整画面，多余空间留边；不得拉伸画面，也不得仅按宽度缩放后裁掉底部。
- 允许两种实现：响应式内部布局，或设计坐标舞台按 `min(可用宽/设计宽, 可用高/设计高)` 等比例缩放。后者须提供窄屏阅读模式，不能只把桌面幻灯片缩成难以阅读的小图。
- 窄屏（默认宽度不大于768 CSS px，可按实际布局调整）及竖屏使用阅读模式：内容按语义顺序重排，多栏变单栏，页面高度自适应，正文允许纵向滚动。保持标题、材料、逻辑关系、来源的顺序；不强迫旋转屏幕。可提供演示/阅读模式切换。
- 导航区与舞台分开计算空间；工具栏不得遮挡正文或页脚。考虑 `env(safe-area-inset-*)`；触控按钮建议至少44×44 CSS px，并支持键盘焦点。
- 图片、视频须 `max-width:100%`；图片仅在不会丢失关键信息时用cover，地图、史料和文物细节优先contain。视频播放器适配所在区域，不随加载撑破版面。

## 二 视口单位与字号

- 舞台与外壳可用vw/vh，移动端优先dvw/dvh，并为不支持的浏览器提供回退。dvh用于跟随浏览器栏变化；不把100vh当作所有手机上的恒定可见高度。
- 正文字号采用rem与有上下限的clamp组合，不只用vw决定字号。以1600×900设计舞台为例，正文可从28—34px、主标题44—64px起步；这是设计参考，须经实际投影检查，不能靠持续缩字适配内容。
- 窄屏阅读正文保持至少1rem，行高约1.5—1.8。投影正文、辅助来源、标题分别设字号层级；缩放后重新检查实际可读性。
- Grid/Flex子项设 `min-width:0; min-height:0`；列宽用 `minmax(0,1fr)`，长链接与不可断长串用 `overflow-wrap:anywhere`。普通中文不滥用word-break:break-all破坏阅读。

参考外壳（仅示范尺寸约束，内部仍须独立排版）：

```css
:root { --controls: 3.5rem; }
* { box-sizing: border-box; }
html, body { margin: 0; }
.shell {
  height: 100vh;
  height: 100dvh;
  display: grid;
  grid-template-rows: minmax(0, 1fr) auto;
  padding: .5rem;
  padding-bottom: max(.5rem, env(safe-area-inset-bottom));
}
.viewport { min-width: 0; min-height: 0; display: grid; place-items: center; }
.slide { aspect-ratio: 16 / 9; max-width: 100%; max-height: 100%; }
.columns { display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); }
.columns > * { min-width: 0; min-height: 0; }
.copy { font-size: clamp(1rem, 1.7vw, 2rem); line-height: 1.6; overflow-wrap: anywhere; }
img, video { max-width: 100%; }
@media (max-width: 768px), (orientation: portrait) {
  .shell { height: auto; min-height: 100dvh; }
  .slide { aspect-ratio: auto; max-height: none; height: auto; }
  .columns { grid-template-columns: 1fr; }
  .copy { font-size: 1rem; }
}
```

若使用固定设计坐标，JS须在resize、方向变化及fullscreenchange时重新测量可用区域；用ResizeObserver观察容器，避免只读取初始窗口尺寸。阅读模式须撤销固定坐标、绝对定位和缩放变换，让内容回到正常文档流。

## 三 溢出处理：发现、重排、拆分

- 核心文字不得用overflow:hidden、line-clamp、ellipsis或遮罩隐藏。幻灯片外壳可以裁切装饰，但必须先证明所有教学内容可见。
- 投影模式正文默认不使用内部滚动条。内容过载按顺序处理：删除重复表达 → 精炼句子 → 调整分区/换行 → 在下限内调字号与间距 → 拆成两页。不得删掉重要事实限定、来源性质或逻辑节点来换取“无溢出”。
- 阅读模式和来源弹窗允许纵向滚动，不允许整页横向溢出。表格先简化列或改为结构化列表；确需横向滚动时，仅表格容器滚动并提供可见提示。
- 不使用无上限的自动缩字算法。若内容不能在字号下限内容纳，应明确触发拆页或重排；不能静默裁切。
- 字体加载、图片加载及视频配置变化后再次检查。动态播放器应有预留空间、缺失状态和错误提示。

## 四 内容自适应与逻辑关系

- 优先使用语义化HTML与正常文档流；绝对定位只用于确需固定的装饰和少数版式元素。正文、核心判断与关系链不要依赖相互独立的底部坐标，以免文字变高后相互覆盖。
- 根据内容长度选择图文、双栏、三栏、时间线或对照表，不将所有内容硬塞进同一模板。固定比例下出现拥挤时允许新增页面，但不自动延长90分钟教学预算。
- 逻辑图在桌面可横排，窄屏改纵排或分行；保留箭头含义、顺序、节点标签与必要的非因果说明。不能只改变节点位置而让连线指向错误。
- 标题允许自然换行，不按固定字符数强插换行。长词、长中文标题、加粗句和来源标签都纳入布局测试。
- 独立视频配置继续使用VIDEO_TOPIC_01等代码，每话题180秒；空地址不发请求，切页暂停。视频外链另开窗口时明确其时长需人工控制。
- 维护页面数据、目录、页码、来源关联与讲稿索引的一致性；拆页后一起更新。说明文件与下载包必须使用同一版本。

## 五 必须实际执行的验收

至少检查1920×1080、1366×768、1024×768、768×1024、390×844五种视口，并测试桌面200%浏览器缩放或等效布局缩放。记录浏览器与尺寸，不能仅凭生成代码宣称响应式已通过。

1. 逐页检查横屏文字完整、无正文重叠、无工具栏遮挡；阅读模式语义顺序正确，所有内容可滚动到达。
2. DOM检查scrollWidth/clientWidth、scrollHeight/clientHeight及内容边界，区分允许滚动容器与实际裁切；对正文、关系带、结论和页脚检查相互重叠。变换舞台须使用一致坐标空间比较。
3. 图片完成加载、字体就绪后截图；检查最长标题、最多文字、最多节点、视频、表格及来源页。几何检查不能替代目视检查。
4. 测试方向键/触控导航、目录、全屏、窗口缩放、来源面板、空视频地址与错误状态。阅读模式不能拦截用户正常滚动；弹窗打开时停止幻灯片翻页快捷键。
5. 教师替换视频后需要再次测试真实播放。尚未提供视频只能验证占位和配置机制，不宣称播放内容与版权已核验。

验收报告明确实际测试与未测项。用户只要求提示词时，将这些约束写入生成要求，不伪称已运行浏览器测试。
